## ✨ Features

- 🎁 **Create & Join Groups** - Easy group creation with shareable invite codes
- 🔐 **Secure Authentication** - Email/password auth powered by Firebase
- 🎲 **Random Assignment** - Fair and secret gift exchange pairing algorithm
- 👥 **Real-time Updates** - See participants join instantly
- 🎨 **Stunning UI** - Interactive backgrounds (Ballpit, Galaxy, DotGrid)
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- 🚀 **Fast & Modern** - Built with Next.js 14 and TypeScript
- 🎯 **Privacy First** - Only you can see your assigned person

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** React Bits Components (Galaxy, Ballpit, ChromaGrid, DotGrid)

### Backend & Database
- **Authentication:** Firebase Auth
- **Database:** Cloud Firestore
- **Hosting:** Vercel (recommended)

### Key Libraries
- `firebase` - Backend services
- `gsap` - Animation engine
- `three.js` - 3D graphics for backgrounds
